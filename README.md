# DVD Rental Store Data Analysis (PostgreSQL)

Advanced SQL analytical queries executed on the PostgreSQL DVD Rental sample database to extract business insights regarding customers, rental behavior, and revenue metrics.

## 🌟 Key SQL Techniques Demonstrated
- **Window Functions:** Computed `running_total`, `SUM OVER()`, `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()`.
- **Common Table Expressions (CTEs):** Structured complex logic to isolate top customer payment ranks.
- **Subqueries & Aggregations:** Filtered films with length above category averages.
- **Database Administration:** Stored Procedures, Views creation, and Role/Permission Management (`GRANT`, `REVOKE`).

## 🛠 Tech Stack
- **Database Engine:** PostgreSQL
- **GUI Tool:** pgAdmin 4
